## The scene

> Dad burned the toast again and blamed the toaster, the bread, and — after a long pause — the weather.
> Mum buttered it anyway and said, "Still the best breakfast in this house, chef."

## How it works

`main.ts` writes the scene (two lines, under 280 characters) to `/output/entry.txt`. It is fully deterministic — every run produces the same bytes — and it checks the gate itself (1–280 characters, 1–2 lines) before writing.

Run it with Node 22:

```sh
node main.ts
```
